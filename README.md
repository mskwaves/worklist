# WorkList

Десктопный планировщик задач на Python и PyQt6. Задачи хранятся в базе SQLite,
поэтому не пропадают при перезапуске.

## Возможности

- Добавление задач с приоритетом: обычный, важный, срочный.
- Поиск по тексту без учёта регистра, включая кириллицу.
- Редактирование задачи двойным кликом.
- Удаление с подтверждением.
- Кнопка «Выполнено»: задача уходит в архив, а не удаляется.
- Окно «Архив»: дата выполнения, приоритет и текст задачи.
- Режим «Фокус»: таймер на 30 минут, лишние кнопки блокируются.
- Тёмная и светлая темы, свои иконки для каждой.
- Сохранение задач в CSV и загрузка из CSV или TXT.
- Сборка в один исполняемый файл `.exe`.

## Технологии

PyQt6, SQLite (`sqlite3`), QSS-стили, PyInstaller.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `MyWorklist.py` | Главное окно: список, поиск, темы, фокус-таймер |
| `db.py` | Работа с SQLite: таблицы `tasks` и `archive` |
| `edit_dialog.py` | Форма редактирования текста задачи |
| `archive_window.py` | Окно выполненных задач |
| `styles/` | `dark.qss` и `light.qss` |
| `icons/` | Иконки для двух тем |
| `requirements.txt` | Зависимости проекта |

## База данных

При первом запуске создаётся файл `tasks.db` с двумя таблицами:

- `tasks` — активные задачи: `id`, `text`, `text_lower`, `priority`;
- `archive` — выполненные: `id`, `text`, `priority`, `archived_at`.

Колонка `text_lower` хранит текст в нижнем регистре — через неё работает поиск,
который не зависит от регистра.

## Установка и запуск

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python MyWorklist.py
```

Требования: Python 3.10+ и PyQt6.

## Сборка в exe

```bat
pyinstaller --noconfirm --onefile --windowed --name main --add-data "icons;icons" --add-data "styles;styles" MyWorklist.py
```

Готовый файл появится в `dist/main.exe`. Папки `icons` и `styles` нужно
добавлять через `--add-data`, иначе приложение не найдёт иконки и темы.

## Формат CSV

Одна задача на строку, кодировка UTF-8. При загрузке задачи добавляются
с приоритетом «Обычный».
