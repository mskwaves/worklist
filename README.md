# WorkList

Простое десктопное приложение для ведения списка задач (todo) на Python + PyQt6.

## Возможности

- Добавление, редактирование и удаление задач
- Приоритет задачи: обычный / важный / срочный
- Две цветовые темы (тёмная и светлая)
- Режим «Фокус» с таймером на 1 минуту

## Установка и запуск

```bash
pip install -r requirements.txt
python MyWorklist.py
```

## Требования

- Python 3.10+
- PyQt6

Задачи сохраняются в CSV-файл через кнопки «Сохранить / Загрузить CSV».
